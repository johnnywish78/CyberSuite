Network Checker
Network tools for your own internet connection
Scan clean IPs
Probes Cloudflare edge IP ranges over TLS and reports the IPs that are reachable from your network. Use them to pin your panel or subscriptions to unfiltered IPs.
Note.

The scan runs directly over your local connection and takes a few seconds to a few minutes depending on the sample size.

Domain Checker
Checks whether websites are reachable over TLS from your connection. Blank uses a list of popular domains.
DNS Latency Test
Measures DNS query latency for the well-known DNS providers.
Vless Config Modifier
Replace the address of each vless:// config with every clean IP you provide (one per line).
SNI Spoof Check
Checks whether SNI spoofing is possible on your connection.
DNS Hunter
Asks Iranian DNS providers how they resolve a domain. Blank uses a default domain.
CDN Xray Scanner
Scans CDN IP ranges against your Xray JSON config and reports the reachable IPs. Runs via TCP/TLS probes, no Xray binary needed.
Akamai IP Scan
Scans Akamai edge IP ranges over TLS and reports the reachable ones.
Netlify Config Generator
Generates multiple netlify.toml configs from SNIs and IPs.
Internet Diagnostics
Runs automated tests over your connection: DNS latency, TCP connect, TLS handshake and DNS resolution for each target.
